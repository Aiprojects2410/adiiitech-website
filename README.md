# 🚀 Adiiitech_ — Cyberpunk Influencer Hub & Admin Control Panel

A futuristic Cyberpunk dark & neon themed website designed for tech influencers to share modded apps, curated tips & tricks, free digital resources, and community links with a full-featured client-side Admin Control Panel.

---

## ✨ Features

- 🎨 **Futuristic Cyberpunk UI**: Orbitron & Rajdhani typography with interactive particle canvas, scanline overlays, glassmorphism cards, and neon glow accents.
- 📦 **Modded Apps Vault**: Dynamic cards showcasing modded APKs with version tags, features badges, file size, safe badges, and download triggers.
- 💡 **Knowledge Base (Tips & Tricks)**: Interactive category filtering (Android, PC, Gaming, iOS) with fast live transitions.
- 📁 **Resource Hub**: Free PDF guides, tools, and configs.
- 👥 **About & Social**: Influencer stats counters, bio, and direct links to Telegram, Instagram, YouTube, and WhatsApp.
- 🔐 **Admin Control Panel (`admin.html`)**:
  - Secure authentication with email (`collab.ahad@gmail.com`) and password (`adiiitech2025`).
  - Full CRUD operations: Add/Edit/Delete Apps, Tips, Resources.
  - Manage Social handles, Hero counters, Bio, and credentials.
  - Real-time sync with main site via `localStorage`.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5 Semantic, Vanilla CSS3 (Custom Design System, Flexbox, Grid), Vanilla JavaScript (ES6+).
- **Icons & Fonts**: Google Fonts (Orbitron, Rajdhani) & Inline Vector SVGs.
- **Hosting Ready**: Compatible with Netlify, Vercel, GitHub Pages, or any static hosting.
